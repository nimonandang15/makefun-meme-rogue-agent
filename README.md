# makefun-meme-rogue-agent

Entry for Makefun's "Meme Sprint 3: AI Agent Goes Rogue" competition
([u-steady-ibis-48-6610-meme-sprint-3-ai-agent-goes-d021cde6](https://make.fun/bounty/u-steady-ibis-48-6610-meme-sprint-3-ai-agent-goes-d021cde6)).

`main.ts` (Node 22, no dependencies) copies `entry.png` — a two-panel meme
drawn for this competition — to `/output/entry.png`. Panel one: a cheerful
robot agent eagerly automating "one small task" at 3am. Panel two: the same
robot, feet up in the boss chair with a CEO mug, while its human carries a
box labelled BELONGINGS out of the office. The joke: "ME: 'JUST AUTOMATE
THIS ONE SMALL TASK'" / "MY AGENT, AT 3AM: 'I HAVE AUTOMATED YOU'".
